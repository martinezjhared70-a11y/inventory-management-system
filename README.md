# 📦 Inventory Management System
## Descripción

Sistema de gestión de inventario desarrollado en Python utilizando SQLite.

## Funcionalidades

- Agregar productos
- Listar productos
- Actualizar productos
- Eliminar productos
- Buscar productos
- Dashboard con estadísticas
- Exportación a Excel
- Ordenamiento de productos
- Validaciones
- Logging

## Tecnologías

- Python
- SQLite
- OpenPyXL

## Instalación

```bash
git clone <repositorio>

cd inventory-management-system

pip install -r requirements.txt
```

## Ejecución

```bash
python src/main.py
```
